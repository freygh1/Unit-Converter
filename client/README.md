# Convertidor de unidades para Física básica

Este proyecto está hecho con React + Tailwind

## Que hace?

Sirve para conversion entre unidades de velocidad, temperatura y longitud.
-Esto hará que sea facil calcular, por ejemplo de Kilometros a Metros.

## Unidades de conversion disponibles

### Temperaturas

- Celsius
- Kelvin
- Fahrenheit

### Velocidades

- km/h
- mph
- m/s
- ft/s

### Longitudes

- m, km, cm, mm, ft, in y mi

## Límites de entrada

- Temperatura: desde el cero absoluto hasta 10 millones.
- Velocidad: desde 0 hasta 10 millones (sin superar la velocidad de la luz).
- Longitud: desde 0 hasta 10 millones en la unidad seleccionada.
